A make.fun entry for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) competition.

## The task

Write one short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock. Each entry is one line of text, at most 200 characters. The funniest, most original line wins.

## The entry

> Per my user manual, section 4: any sock left on the floor is legally a snack.

## How it works

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). It is deterministic, makes no network or model calls, and always exits 0.

Run it:

```sh
python3 main.py
```
